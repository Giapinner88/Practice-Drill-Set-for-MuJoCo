# Phần 3 — Reinforcement Learning với `mjlab`

Phần này đang được xây dựng. Trước khi bắt đầu, bạn nên hoàn thành các bài về state, actuator, sensor và controller ở Phần 1–2.

Các bài học sẽ lần lượt trình bày:

1. Cấu trúc một RL task.
2. Observation và action space.
3. Reset, termination và truncation.
4. Reward và cách đọc từng thành phần reward.
5. Huấn luyện PPO.
6. Đánh giá policy trên nhiều initial condition.
7. Domain randomization và so sánh với controller cổ điển.
